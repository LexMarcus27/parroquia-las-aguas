# Parroquia Nuestra Señora de Las Aguas

Copia estática y responsive del sitio informativo público de la Parroquia Nuestra Señora de Las Aguas, creada como base limpia para su posterior rediseño.

## Contenido

- Portada con ubicación, horarios y datos de contacto.
- Página de Sacramentos.
- Página de Cenizarios.
- Página de horarios de celebraciones y despacho.
- Navegación adaptable a dispositivos móviles.
- Imágenes y tipografías necesarias guardadas localmente.

## Ejecutar localmente

No requiere instalación ni compilación. Puede abrir `index.html` directamente o iniciar un servidor local:

```bash
python -m http.server 8000
```

Luego visite `http://localhost:8000`.
